## 5. DSH 0.1.2 接口核对

- UI 入口采用 `sidebar.footer.action`，没有轮询、查询或改写 DSH 内部 DOM。
- JSON 查询和命令通过 `ctx.connection.rpc` / `connection.rpc.handle`；SSE 与下载使用 Connection 的精确 Fetch 路由。
- Client bundle 只绑定 DSH 公布的 platform 模块；共享 session 类型文件不导入 Node API。
- 无 Connection 的 headless profile 延迟降级，只是不注册工作台数据面，不影响 Agent tool。
- Python 子进程退码、stdout/stderr 和产物语义保持既有实现；迁移没有重写 Contract Copilot skill。
